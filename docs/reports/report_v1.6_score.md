## 一、打分模型（本地规则，离线可用、可解释）

满分 100，逐项扣分后 clamp 到 0–100：

| 维度 | 规则 |
|---|---|
| 超出每日目标 | 按比例扣，最多 45 分（目标 2 倍即扣 45） |
| 深夜使用（23:00–05:00） | 每分钟扣，最多 20 分 |
| 单次超长连续使用 | 超过 30 分钟后每分钟扣，最多 15 分 |
| 高频解锁 | 超过 50 次后每次扣，最多 12 分 |
| 克制加成 | 低于目标 50% +3、无深夜使用 +3 |

等级：`≥90 优秀 / ≥75 良好 / ≥60 一般 / ≥40 偏多 / <40 超负荷`

**时段划分**：清晨 5-9、上午 9-12、下午 12-18、晚上 18-23、深夜 23-5（跨零点）。
判断词条同时看「时长档位（6 档）× 时段分布 × 深夜档位 × 语气 × 称呼」，例如：

- 40 分档 + 深夜偏多 → 词条「有点舍不得放下 · 熬夜偏多」，判断句指出"使用主要集中在深夜（168 分钟，占 76%），这是今天最该改的地方"
- 健康档 → 「节奏不错」「分寸感很好」，判断句给出"使用比较分散/集中在某时段"的具体描述
- 语气（温和/直接/严厉）会改变建议措辞；昵称会出现在判断句开头（当前昵称为空，显示为"你"）

## 二、每日 / 每周总结

| 位置 | 内容 |
|---|---|
| 首页「今日评分」卡 | 大号分数（按等级着色）+ 等级 chip + 词条 + 判断句（≤3 行）+ 5 段时段条形（深夜红色）+ 深夜/最长连续/打开次数 |
| 报告页「今日评分」卡 | 同上（42sp 分数、时段占比条） |
| 报告页「本周总结」卡 | 平均分 + 等级 + 词条 + 趋势徽标 + 判断句 + 日均/超目标天数/深夜天数 + 最佳/最需留意日 |
| 本地日报文本 | 最前面【今日评分】段：分数·等级·词条 → 判断句 → 时段分布 → 明细 |
| 本地周报文本 | 最前面【本周总结】段：平均分·等级·词条 → 判断/建议 → 超目标/深夜天数·趋势 → 最佳/最差日 |
| AI 日报/周报 | 生成前先调 `get_usage_score`，报告开头写「今日 30 分（超负荷）· 有点舍不得放下 · 熬夜偏多」 |
| 通知 | 日报/周报通知首行带分数；每日提醒（19–21 点）首行「今天 X 分 · 词条」 |
| 落库 | `daily_score` 表（date/score/grade/headline/verdict/total/slots JSON…），同步后与报告页刷新时写入 |
